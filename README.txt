귀살의 길 — 모바일 스토리 RPG 웹게임

이 폴더는 정적 웹사이트로 바로 배포할 수 있는 버전입니다.

파일:
- index.html : 실제 게임
- manifest.json : 모바일 홈 화면 설치/PWA 설정
- sw.js : 첫 방문 후 오프라인 실행을 위한 캐시
- icons/ : 앱 아이콘

배포:
1. 이 폴더 전체를 정적 웹호스팅에 업로드합니다.
2. index.html이 사이트의 시작 페이지입니다.
3. HTTPS로 접속하면 iPhone/Android에서 홈 화면에 추가할 수 있습니다.

주의:
- 개인 소장용 팬게임 기준으로 구성되어 있습니다.
- 공개 배포/수익화 전에는 사용한 캐릭터·이미지·세계관의 권리 관계를 확인하세요.
